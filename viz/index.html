Repeatable boxes, one cell each. Cell is an unstructured gmsh mesh — a round body spanning the box in x, with two round connectors that cross it while leaning in x. The lattice is shifted so every cell is a pure translate and all connectors lean the same way; the shift wraps every few boxes, so rows zig-zag rather than marching off diagonally. Plus is the original structured 3D-plus voxel grid (exactly equal ECS/ICS volumes). Existing configurations are reused; new ones are generated on demand.
